# Executing Serial and Parallel Workflows Using CrewAI Agents 
 ## Objective: To demonstrate how to build intelligent workflows using CrewAI agents that 
execute tasks either sequentially (serial) or independently (parallel) 
 
This demo highlights how tasks can be structured based on interdependence or 
concurrency. 
 
## Scenario: A product leader at a global FMCG company requires timely insights on how AI is 
reshaping product development, consumer engagement, and supply chain efficiency. 
Manually gathering and summarizing this information is time-consuming and slows product 
strategy decisions. To solve this, the workflow can be automated with AI agents—one 
dedicated to researching the latest AI trends in FMCG and another to generating executive-
ready summaries. This enables the product team to make faster, data-informed decisions in 
a highly competitive market. 
 
## Tools required: 
Visual Studio Code 
 
## Prerequisites: 
Azure OpenAI API key 
 
## Steps to be followed: 
 
1. Set up your local environment in Visual Studio Code 
2. Configure the Tavily API Key and Azure OpenAI model  
3. Define agents and tasks 
4. Define and run parallel tasks
